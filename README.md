# Portfólio

Single Page Application (SPA) desenvolvida em JavaScript puro para apresentação de projetos e trajetórias profissionais. Possui roteador próprio para navegação dinâmica entre telas sem recarregamento, animações com aceleração de hardware via GSAP, alternância de temas e layout responsivo.

Acesse em: [enrique-ss.github.io/portifolio](https://enrique-ss.github.io/portifolio)

## Como rodar

Clone o repositório e abra o arquivo `index.html` em seu navegador.

## Stack

HTML5, CSS3, JavaScript (ES6+) e biblioteca GSAP para animações.
